# Nightwatch v0.6 "Night Watch" Implementation Plan

**Goal:** Small, medium and large desktop widgets that draw a snapshot the app writes after each patrol, with click-through to the Targets window, shipped as v0.6.0.

**Architecture:**
- **Shared views:** the bezel, bars, warning dot, tokens and target glyphs move into a new SwiftPM library target, `NightwatchUI`. The bars become data-driven (`ClearSkyBar` in SkyCore), so a widget can draw them without a `NightPlan`.
- **The snapshot:** SkyCore gains `WidgetSnapshot` (everything the widget draws, as plain values) and `WidgetLink` (the `nightwatch://` URLs).
- **Writing it:** after each recompute, the app writes `widget.json` into the App Group container (`<TEAM>.io.github.rsutcliffe.nightwatch`, spike-proven) and reloads WidgetKit.
- **Building the widget:** it lives in `Widget/`. An xcodegen `project.yml` references the root package. `scripts/build-app.sh` builds the `.appex` with `xcodebuild` when Xcode and xcodegen are present, then embeds it in the SwiftPM-built app before signing. Without them, the app builds exactly as today.

**Tech Stack:** Swift 6.4 and SwiftPM for the app, Xcode 27 plus xcodegen for the widget extension only, WidgetKit, Swift Testing.

**Spec:** `docs/specs/2026-09-25-v0.6-night-watch-widgets-design.md`, including §4's spike results. The visual target is the owner-approved mockup canvas.

## Global Constraints

- **PRs and merging:** one PR per task, serial, each with `No-issue:` and `**UAT:**`. The owner's instruction, 25 September 2026: "plan and build it", with the merge-on-green authority of v0.5. Green means the tests pass, the release build is clean, and the task review finds no Critical or Important issue.
- **Commits:** never use the words "time-boxed", "deferred", "partial" or "out of scope".
- **The app:** a SwiftPM executable, as before. `swift build` and `scripts/test.sh` need only the Command Line Tools. No `@State` in the app or `NightwatchUI`. The package floor stays macOS 14. No generated `.xcodeproj` is committed; `Widget/*.xcodeproj` is gitignored.
- **The widget:** it never fetches anything. It reads `widget.json` only. Nothing is logged: each patrol replaces the file.
- **App Group ID:** `<TEAM>.<app bundle id>`, as in the spike. The build script writes it into the app's `Info.plist` as `NightwatchAppGroup`. The widget's `Info.plist` carries the same key through `$(TeamIdentifierPrefix)`. The app writes the snapshot only when the key is present and the container resolves.
- **Colour:** red means clear sky only. Tokens are as v0.4, warnings are amber, and the stale age is six hours.
- **URLs:** `nightwatch://targets` opens the Targets window; `nightwatch://target/<id>` opens that target.

## Review Focus

1. **Command Line Tools-only build** (no Xcode or xcodegen). It must build and install the app as before, with no widget, and nothing may abort. Checked in Task 3 by running the script with `DEVELOPER_DIR=/Library/Developer/CommandLineTools`.
2. **A snapshot from a night with no darkness or no window.** Every optional field must be nil or empty, never a crash or a "0.0 h" window. Pinned by `snapshotWithNoDarkness` in Task 2.
3. **Stale forecast.** The widget must show "Forecast N h old" from `fetchedAt` against the clock at render time, not at write time. Pinned by `snapshotStaleText` in Task 2.
4. **A `nightwatch://target/<id>` for a target no longer in tonight's list.** The Targets window must still open, without crashing or selecting anything. Pinned by `widgetLinkRoundTrip` in Task 4, plus the view guard.
5. **The bars after the refactor.** They must match 0.5.2 exactly: lit by window overlap, peak label only when above 0%. Pinned by `clearSkyBarsMatchTheOldRule` in Task 1.

### Task 2: `WidgetSnapshot` and writing it after each patrol

**Files:**
- Create: `Sources/SkyCore/WidgetSnapshot.swift`
- Create: `Tests/SkyCoreTests/WidgetSnapshotTests.swift`
- Modify: `Sources/Nightwatch/Store.swift` (write after `recompute`)

**Interfaces:**
- Consumes: Task 1's `ClearSkyBar`, `clearSkyBars`, `barsLabel` and `noWindowReasonText`; `Bezel.slots`, `Copy.bezelLabel`, `Copy.heldBack`, `Copy.agreementText`, `Copy.notifyLabel`, `Planner.moonTonight`
- Produces:

```swift
public struct WidgetTarget: Codable, Equatable, Sendable {
    public var id: String, catalogueID: String, name: String, best: String, group: TargetGroup
}
public struct WidgetSnapshot: Codable, Equatable, Sendable {
    public var siteName: String
    public var fetchedAt: Date
    public var score: Int
    public var mode: PlanMode
    public var headline: String          // "Clear window tonight", "Bright night: Moon and planets", the no-window line, "No astronomical darkness"
    public var window: String?           // "21:00 → 01:00 · 4.0 h"
    public var windowShort: String?      // "Clear 21:00–01:00" (small widget)
    public var reason: String?           // "Held back by …" (warns) or the no-window reason (plain)
    public var reasonWarns: Bool
    public var agreement: String?
    public var agreementWarns: Bool
    public var slots: [BezelSlot]
    public var bezelLabel: String
    public var bars: [ClearSkyBar]
    public var barsLabel: String
    public var targets: [WidgetTarget]   // best three, or bright targets, at most 3
    public var tomorrow: String?         // "Tomorrow 20:55–05:00" when tonight has no window
    public var notify: String?           // Copy.notifyLabel
    public static func make(plan: NightPlan, tomorrow: NightPlan?, fetchedAt: Date, site: Site, rule: GoRule,
                            bright: BrightSettings, alerts: AlertSettings, copy: Copy) -> WidgetSnapshot
    /// "Forecast 7 h old" when `now` is more than six hours after `fetchedAt`; nil otherwise.
    public func staleText(now: Date) -> String?
}
```

- [ ] **Step 1: Write the failing tests.** In `WidgetSnapshotTests.swift`, with Home plans built as in `AgreementTests`:
  - `snapshotForAClearNight`: the headline is "Clear window tonight"; `window`, `windowShort`, 60 `slots`, bars and the notify text are set; there are at most 3 targets.
  - `snapshotForNoWindow`: the headline is `copy.noWindow`; `window` is nil; `reason` is the plain no-window reason (`reasonWarns == false`); `tomorrow` is set when tomorrow has a window.
  - `snapshotWithNoDarkness`: the headline is "No astronomical darkness"; the slots are all `.daylight`; the bars are empty; there is no window.
  - `snapshotForABrightNight`: the headline is "Bright night: Moon and planets"; `targets` come from the bright targets.
  - `snapshotCarriesAgreement`: `plan.agreement = .cloudFrom(t)` gives the matching text, with `agreementWarns`.
  - `snapshotStaleText`: nil at `fetchedAt + 5 h`; "Forecast 7 h old" at `+ 7 h 20 m`.
  - `snapshotRoundTrips`: an ISO 8601 JSON encode and decode gives an equal value.
- [ ] **Step 2: Run.** Expected: they fail to compile.
- [ ] **Step 3: Implement `WidgetSnapshot.make`.** Build it from the existing SkyCore helpers only. No new wording, except "Forecast N h old".
- [ ] **Step 4: Write it from the Store.** At the end of `recompute`, after the plans are set:

```swift
        if let group = Bundle.main.object(forInfoDictionaryKey: "NightwatchAppGroup") as? String,
           let dir = FileManager.default.containerURL(forSecurityApplicationGroupIdentifier: group) {
            let snap = WidgetSnapshot.make(plan: p, tomorrow: t, fetchedAt: fc.fetchedAt, site: site, rule: config.goRule,
                                           bright: config.brightNights, alerts: config.alerts, copy: copy)
            let enc = JSONEncoder(); enc.dateEncodingStrategy = .iso8601
            if let data = try? enc.encode(snap) {
                try? data.write(to: dir.appendingPathComponent("widget.json"), options: .atomic)
                WidgetCenter.shared.reloadAllTimelines()
            }
        }
```

  This needs `import WidgetKit` in `Store.swift`.
- [ ] **Step 5: Run.** Tests, the release build and the install pass. Nothing is written yet, because the build script adds `NightwatchAppGroup` in Task 3.

### Task 4: Click-through

**Files:**
- Create: `Sources/SkyCore/WidgetLink.swift`
- Test: `Tests/SkyCoreTests/WidgetSnapshotTests.swift`
- Modify:
  - `Sources/Nightwatch/NightwatchApp.swift` (`AppDelegate`, URL handling, opening the window from the menu-bar label view)
  - `Sources/Nightwatch/Info.plist` (`CFBundleURLTypes`, scheme `nightwatch`)
  - `Sources/Nightwatch/Views/TargetsView.swift` (`TargetsRequest.targetID`, selecting that target)
  - `Widget/Sources/NightwatchWidget.swift` (use `WidgetLink`)

**Interfaces:**
- Produces: `enum WidgetLink: Equatable { case targets, target(String) }`, with `var url: URL` and `init?(url: URL)`

- [ ] **Step 1: Write the failing test.** `widgetLinkRoundTrip` checks that:
  - `.targets` and `.target("NGC7000")` survive `url` then `init?(url:)`
  - an id with a space or `+` survives, because it is percent-encoded
  - `https://…` and `nightwatch://unknown` return nil
- [ ] **Step 2: Implement `WidgetLink`,** percent-encoding the id with `.urlPathAllowed`.
- [ ] **Step 3: Handle the URL in the app.**
  - The app declares `CFBundleURLTypes` with scheme `nightwatch`.
  - An `@NSApplicationDelegateAdaptor` `AppDelegate` passes `application(_:open:)` URLs to a static handler that `boot()` sets. The handler sets `store.targetsRequest = TargetsRequest(section: .group(group of the target, or .nebulae), siteID: nil, targetID: id)`.
  - The menu-bar label view, which is always alive, observes `store.targetsRequest` and calls `openWindow(id: "targets")` and `NSApp.activate`.
  - `TargetsView.consumeRequest` selects the target when `targetID` matches one in tonight's list. Otherwise it opens the section only.
- [ ] **Step 4: Verify.** Tests and the build pass. Live: `open nightwatch://targets` from the shell opens Targets, and `open nightwatch://target/<an id from plan.json>` opens that target's detail. Then the owner clicks the widget and a large widget's row.
- [ ] **Step 5: Commit and PR.** Commit message: `feat: widget click-through to Targets and to a target`.

`**UAT:** Click the widget → the Targets window opens on tonight; on the large widget click a target row → that target's detail opens.`
