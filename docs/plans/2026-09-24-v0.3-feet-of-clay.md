# Nightwatch v0.3 "Feet of Clay" Implementation Plan

**Goal:** Bright-night mode (Moon and planets when the dark rule cannot be met, opt-in), completion of the best-spot path (popover line lands on the dark-site card; cards compare score and darkness with home), and site-cache pruning, shipped as v0.3.0.

**Architecture:** SkyCore gains nautical twilight on `Night`, a `BrightRule` on `Config`, a `PlanMode` on `NightPlan` with `Planner.brightPlan`, bright alert copy, and a pure cache-pruning selector. The app gains a `TargetsRequest` on `Store` so the popover can land on a card, three view changes, and the pruning call. Nothing changes for a normal dark night or for a user with bright nights off.

**Tech Stack:** Swift 6.4 via Command Line Tools, SwiftPM only, Swift Testing through `scripts/test.sh`, Astronomy Engine (vendored C), SwiftUI `MenuBarExtra`.

**Spec:** `docs/specs/2026-09-24-v0.3-feet-of-clay-design.md`

## Global Constraints

- Every task is its own pull request against `main`, branched from the merged `main` after the previous task's PR is merged (tasks are serial). PR body carries a `No-issue:` line and a `**UAT:**` line. The owner merges; never commit to `main`.
- Banned words in commits, PR bodies and reports: "time-boxed", "deferred", "partial", "out of scope".
- Never `@State` (does not compile with the Command Line Tools); view state lives in `ObservableObject` view models. Tests only via `scripts/test.sh`. `swift build -c release` must show no errors and no new warnings (three `ld: warning: search path` lines are known).
- Bright-night default is OFF (`BrightSettings.enabled = false`). Bright targets are the Moon and planets only; `targets` and `best` stay empty in bright mode.
- No new Discworld copy. New strings are the same in both wording modes: "Bright night: Moon and planets", "Bright night tonight from HH:MM · Moon 62%, Saturn", "Bright night. Clear from HH:MM", "Tomorrow looks bright and clear · 2.5 h".
- Nautical twilight is the Sun at −12°, found with `Astronomy_SearchAltitude` exactly as the −18° crossings are. Bright rule default `minHours = 1` (owner ruling 24 September 2026, amended from 2); cloud limit and minimum altitude come from the dark `GoRule`.
- An hour counts toward a bright window only when it is clear and a bright target stands at `Planner.brightTargetFloorDeg` (15°, owner ruling 24 September 2026) or higher at the hour's centre: the Moon with illumination ≥ 0.10, or Mercury, Venus, Mars, Jupiter or Saturn.
- In bright mode the score's Moon term is the full 15 points (pass `moonIllumination: 0`).
- `NightPlan` gains `mode` and `brightTargets` with defaults so existing memberwise callers compile. A cached `plan.json` written by 0.2.x will fail to decode once (missing keys); `Store` already treats a failed read as no plan and recomputes at boot. That one-time cache miss is accepted.
- Site cache pruning keeps only `<id>.json` for ids in the current `darkSites` and nothing older than 24 h; any file error is ignored.

    /// The Sun's descent below `altDeg` after `after` and its return above it, both before `before`; nil when either is missing.
    private static func sunCrossings(altDeg: Double, obs: astro_observer_t, after: astro_time_t, before: astro_time_t) -> (Date, Date)? {
        let down = Astronomy_SearchAltitude(BODY_SUN, obs, DIRECTION_SET, after, 1.0, altDeg)
        guard down.status == ASTRO_SUCCESS, down.time.ut < before.ut else { return nil }
        let up = Astronomy_SearchAltitude(BODY_SUN, obs, DIRECTION_RISE, down.time, 1.0, altDeg)
        guard up.status == ASTRO_SUCCESS, up.time.ut <= before.ut + 1e-6 else { return nil }
        return (down.time.date, up.time.date)
    }

    /// Hourly samples overlapping [from, to). Same rule as `darkHours` with explicit bounds.
    static func hours(_ hours: [HourlyConditions], from: Date, to: Date) -> [HourlyConditions] {
        hours.filter { $0.time.addingTimeInterval(3600) > from && $0.time < to }.sorted { $0.time < $1.time }
    }

    /// The Moon (10 % lit or more) and planets above the minimum altitude at `at`, Moon first, then by altitude.
    public static func brightTargets(at: Date, site: Site, rule: GoRule) -> [RankedTarget] {
        var out: [RankedTarget] = []
        let moon = Ephemeris.moon(at: at, site: site)
        if moon.illumination >= 0.10, moon.position.altDeg >= rule.minAltitudeDeg {
            out.append(RankedTarget(id: "moon", name: "Moon", subtitle: "\(Int((moon.illumination * 100).rounded()))% illuminated", group: .planets,
                                    raHours: moon.position.raHours, decDeg: moon.position.decDeg, sizeArcmin: 31, magnitude: nil, fit: .fits,
                                    peakAltDeg: moon.position.altDeg, peakTime: at, moonSepDeg: 0, moonWashed: false, visibleFraction: 1))
        }
        let planets = Planet.allCases.compactMap { p -> RankedTarget? in
            let pos = Ephemeris.planet(p, at: at, site: site)
            guard pos.altDeg >= rule.minAltitudeDeg else { return nil }
            return RankedTarget(id: "planet-\(p.rawValue)", name: p.displayName, subtitle: "Planet", group: .planets,
                                raHours: pos.raHours, decDeg: pos.decDeg, sizeArcmin: nil, magnitude: pos.magnitude, fit: .small,
                                peakAltDeg: pos.altDeg, peakTime: at, moonSepDeg: 0, moonWashed: false, visibleFraction: 1)
        }.sorted { $0.peakAltDeg > $1.peakAltDeg }
        return out + planets
    }

    /// The bright-night plan: clear runs between nautical dusk and dawn that have the Moon or a planet up.
    static func brightPlan(night: Night, forecast: Forecast, site: Site, rule: GoRule, bright: BrightSettings) -> NightPlan {
        guard let ns = night.nauticalStart, let ne = night.nauticalEnd else {
            return NightPlan(night: night, windows: [], primary: nil, score: 0, qualifies: false, moonIllumination: 0, moonRise: nil, moonSet: nil,
                             darkHours: [], targets: [], best: [], seeingAvailable: false, mode: .bright, brightTargets: [])
        }
        let hrs = hours(forecast.hours, from: ns, to: ne)
        let brightRule = GoRule(minHours: bright.minHours, maxCloudPct: rule.maxCloudPct, minAltitudeDeg: rule.minAltitudeDeg)
        let windows = Planner.windows(hours: forecast.hours, darkStart: ns, darkEnd: ne, rule: brightRule)
            .filter { !brightTargets(at: $0.midpoint, site: site, rule: rule).isEmpty }
        let primary = windows.max { $0.hours < $1.hours }
        let moon = Ephemeris.moon(at: primary?.midpoint ?? ns, site: site)
        let score = Planner.score(ScoreInputs(darkHours: hrs, windows: windows, darkness: (ns, ne), moonIllumination: 0, moonAboveFraction: 0, maxCloudPct: rule.maxCloudPct))
        return NightPlan(night: night, windows: windows, primary: primary, score: score, qualifies: primary != nil,
                         moonIllumination: moon.illumination, moonRise: moon.rise, moonSet: moon.set,
                         darkHours: hrs, targets: [], best: [], seeingAvailable: hrs.contains { $0.seeing != nil },
                         mode: .bright, brightTargets: primary.map { brightTargets(at: $0.midpoint, site: site, rule: rule) } ?? [])
    }
```

import Foundation

/// Which site-forecast cache files to delete: anything not `<id>.json` for a current id, and anything older than `maxAge`.
public enum CachePruning {
    public static func filesToDelete(names: [String], modified: [String: Date], keepIDs: Set<String>, now: Date, maxAge: TimeInterval = 86_400) -> [String] {
        names.filter { name in
            guard name.hasSuffix(".json"), keepIDs.contains(String(name.dropLast(5))) else { return true }
            guard let m = modified[name] else { return false }
            return now.timeIntervalSince(m) > maxAge
        }
    }
}
```

```swift
    /// Keeps the sites/ cache to the current list and the last 24 h. Errors are ignored: the cache is disposable.
    private func pruneSiteCache(keep: Set<String>, now: Date) {
        let fm = FileManager.default
        guard let names = try? fm.contentsOfDirectory(atPath: Store.siteCacheDir.path) else { return }
        var modified: [String: Date] = [:]
        for n in names { modified[n] = (try? fm.attributesOfItem(atPath: Store.siteCacheDir.appendingPathComponent(n).path)[.modificationDate]) as? Date }
        for n in CachePruning.filesToDelete(names: names, modified: modified, keepIDs: keep, now: now) {
            try? fm.removeItem(at: Store.siteCacheDir.appendingPathComponent(n))
        }
    }
```
