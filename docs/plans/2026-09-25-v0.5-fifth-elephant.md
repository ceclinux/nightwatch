# Nightwatch v0.5 "The Fifth Elephant" Implementation Plan

**Goal:** Fetch Open-Meteo as a second opinion beside Apple Weather, show one agreement line in the popover and alerts, and offer an opt-in "Alert only when Open-Meteo agrees", shipped as v0.5.0.

**Architecture:**
- `ForecastService.fetch` keeps Open-Meteo's hourly cloud beside the primary hours as `Forecast.secondOpinion`, for the active site only.
- `Planner.agreement` compares the two under the go rule and stores an `Agreement` on `NightPlan`.
- `Copy` turns it into words.
- `AlertEngine` consults it when `AlertSettings.requireAgreement` is on.

**Tech Stack:** Swift 6.4 via the Command Line Tools, SwiftPM, Swift Testing through `scripts/test.sh`, SwiftUI.

**Spec:** `docs/specs/2026-09-25-v0.5-fifth-elephant-agreement-design.md`

## Global Constraints

- Every task is its own PR against `main`, serial, with a `No-issue:` line and a `**UAT:**` line.
- Merge authority (owner, 25 September 2026): "Proceed. Merge the PR when green."
  - Green means `scripts/test.sh` passes, the release build is clean, and the task review finds no Critical or Important issue.
  - Merge with `gh pr merge <N> --squash --delete-branch`.
- Never use these words in commits, PR bodies or reports: "time-boxed", "deferred", "partial" or "out of scope".
- No `@State`. No Xcode project. The package floor stays macOS 14.
- Apple Weather stays primary. Open-Meteo never drives the verdict, score, bars or windows.
- Nothing is logged (owner, 25 September 2026: logging is closed). The second opinion lives only in `forecast.json` and is replaced every patrol.
- The second opinion is fetched for the active site only. Dark-site forecasts pass `secondOpinion: false`.
- The line wording is exactly as spec §4, the same in both wording modes, with no Discworld copy:
  - "Open-Meteo agrees"
  - "Open-Meteo sees cloud from HH:MM"
  - "Open-Meteo sees no clear window"
  - "Open-Meteo agrees: no clear window"
  - "Open-Meteo has a clear run HH:MM–HH:MM"
- Red means clear sky only. The line is text.secondary 10 pt, with an amber `WarningDot` for a disagreement and a small tick for agreement.
- Old files must decode: a 0.4 `forecast.json` (no `secondOpinion`) and a 0.4 `config.json` (no `requireAgreement`).

## Review Focus

1. **Open-Meteo lacking an hour the comparison needs** (its 3-day horizon, a gap). The line must hide (nil), never read as a false "no clear window". Pinned by `agreementIsNilWhenAHourIsMissing` in Task 2.
2. **A 0.4 config.json with no `requireAgreement` key.** Settings must survive with every other alert setting kept, not reset to defaults. Pinned by `alertSettingsFromZeroFourDecode` in Task 4.
3. **A window that starts part-way through an hour** (darkness clips it). The "cloud from" time must never read earlier than the window start. Pinned by `cloudFromIsClampedToTheWindowStart` in Task 2.
4. **"Alert only when Open-Meteo agrees" switched on in an unsigned build**, where there is no second opinion. Alerts must still fire. Pinned by `requireAgreementWithoutSecondOpinionStillAlerts` in Task 4.
5. **Dark-site patrols.** They must make no extra Open-Meteo calls. Pinned by `fetchWithoutSecondOpinionMakesOneOpenMeteoCallAtMost` in Task 1.

```swift
import Foundation

/// What the second opinion (Open-Meteo) says about tonight, under the same go rule (v0.5 spec §3.2).
public enum Agreement: Codable, Equatable, Sendable {
    case agree
    case cloudFrom(Date)
    case noWindow
    case agreeNoWindow
    case clearRun(Date, Date)
}

extension Planner {
    /// nil when there is no second opinion, no darkness, or the second source lacks an hour the comparison needs.
    public static func agreement(plan: NightPlan, second: SecondOpinion?, rule: GoRule) -> Agreement? {
        guard let second, let span = plan.darkSpan, !plan.darkHours.isEmpty else { return nil }
        let cloud = Dictionary(second.hours.map { ($0.time, $0.cloudTotal) }, uniquingKeysWith: { a, _ in a })
        guard plan.darkHours.allSatisfy({ cloud[$0.time] != nil }) else { return nil }
        let hours = plan.darkHours.map { h in
            HourlyConditions(time: h.time, cloudTotal: cloud[h.time]!, cloudLow: nil, cloudMid: nil, cloudHigh: nil, tempC: nil, dewPointC: nil,
                             humidityPct: nil, windKmh: nil, gustKmh: nil, visibilityM: nil, seeing: nil, transparency: nil)
        }
        if let w = plan.primary {
            let inside = hours.filter { w.overlapsHour(startingAt: $0.time) }
            guard let firstCloudy = inside.first(where: { $0.cloudTotal > rule.maxCloudPct }) else { return .agree }
            let runs = windows(hours: inside, darkStart: w.start, darkEnd: w.end, rule: rule)
            return runs.isEmpty ? .noWindow : .cloudFrom(max(firstCloudy.time, w.start))
        }
        guard plan.mode == .dark else { return nil }   // a bright run also needs a target 15° up: not suggested from cloud alone
        guard let best = windows(hours: hours, darkStart: span.start, darkEnd: span.end, rule: rule).max(by: { $0.hours < $1.hours }) else {
            return .agreeNoWindow
        }
        return .clearRun(best.start, best.end)
    }

    /// The opt-in "Alert only when Open-Meteo agrees" holds back an alert only on `.noWindow`; no second opinion never blocks.
    public static func agreementHolds(_ a: Agreement?) -> Bool { a != .noWindow }
}
```

- In `brightPlan`, build the returned plan into `var p`, set `p.agreement = agreement(plan: p, second: forecast.secondOpinion, rule: brightRule)`, and return `p`.

    /// The v0.5 agreement line, the same in both wording modes.
    public static func agreementText(_ a: Agreement, site: Site) -> String {
        switch a {
        case .agree: "Open-Meteo agrees"
        case .cloudFrom(let t): "Open-Meteo sees cloud from \(hhmm(t, site: site))"
        case .noWindow: "Open-Meteo sees no clear window"
        case .agreeNoWindow: "Open-Meteo agrees: no clear window"
        case .clearRun(let a, let b): "Open-Meteo has a clear run \(hhmm(a, site: site))–\(hhmm(b, site: site))"
        }
    }

    /// Amber dot when Open-Meteo disagrees; a tick when it agrees.
    public static func agreementWarns(_ a: Agreement) -> Bool {
        switch a { case .agree, .agreeNoWindow: false; default: true }
